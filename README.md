# 🛠️ UtilityHub - All-in-One Online Tools

**UtilityHub** is a high-performance, privacy-focused collection of web-based tools designed to handle daily productivity tasks—like PDF manipulation, image editing, and text processing—entirely within your browser.

🚀 **Live Demo:** [https://aka2114sh.github.io/utility-hub/](https://aka2114sh.github.io/utility-hub/)
                  https://v0-utility-hub-build.vercel.app/
                  

---

## 🌟 Key Features

- **100% Client-Side:** No files are ever uploaded to a server. All processing (PDF conversion, background removal, etc.) happens locally in your browser.
- **Privacy First:** Since data never leaves your machine, it is the most secure way to handle sensitive documents and images.
- **Lightning Fast:** Powered by Next.js 15 and Web Workers for near-instant execution.
- **Dark Mode Support:** Clean, modern UI that adapts to your system preferences.
- **Responsive Design:** Optimized for both desktop and mobile productivity.

---

## 🧰 Available Tools

### 📄 PDF Tools
- **PDF to Text:** Extract raw text from any PDF document.
- **PDF to Word:** Convert PDF files into editable `.docx` formats locally.

### 🖼️ Image Tools
- **Background Removal:** Strip backgrounds from images using AI-powered WASM.
- **Image Compressor:** Reduce file size without losing quality.
- **Image Upscale:** Enhance resolution using client-side scaling.

### ✍️ Text & Productivity
- **Voice Typing:** Real-time speech-to-text using the Web Speech API.
- **Translation:** Translate text across multiple languages.
- **Age Calculator:** Detailed breakdown of age, next birthday, and milestones.

## 🚀 Technical Stack

- **Framework:** [Next.js (App Router)](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Libraries:** 
  - `pdf-lib` & `pdfjs-dist` (PDF Processing)
  - `docx` (Word Document Generation)
  - `lucide-react` (Icons)
  - `framer-motion` (Animations)
- **Deployment:** [GitHub Pages](https://pages.github.com/) & [Vercel](https://vercel.com/)
